# ESP32-Based RFID ID Card Detection System

## Project Overview

This project uses an ESP32 microcontroller and an RDM6700 RFID reader module to identify RFID cards or tags.

The system reads the card's identification number and records entry or exit events according to the implemented program logic.

## Hardware Components

- ESP32 development board
- RDM6700 RFID reader module
- Compatible RFID card or tag
- Jumper wires and prototyping hardware

## Key Features

- RFID card identification
- Reading card identification numbers
- Entry/exit event logging, according to the implemented logic
- ESP32-based embedded system

## Technologies

- ESP32
- RFID
- Embedded Systems
- Microcontroller interfacing
